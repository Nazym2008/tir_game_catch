Tir Game – 2D ойын

Ойын туралы

Бұл жоба Python тілінде Tkinter кітапханасы арқылы жасалған 2D «Тир» ойыны.

Ойынның мақсаты

Ойыншының мақсаты – нысаналарды атып, мүмкіндігінше көп ұпай жинау.

Ойын мүмкіндіктері

* Оқ ату.
* Нысаналарды қозғалту.
* Ұпай жинау.
* Уақытты бақылау.
* Деңгейлерден өту.

Кластардың міндеттері

GameObject – ойын объектілерінің негізгі класы. Объектінің орналасуы мен өлшемін сақтайды.

Target – нысананы басқарады. Нысананың орналасуына және қозғалысына жауап береді.

Bullet – оқтың қозғалысы мен жылдамдығын басқарады.

Қолданылған технологиялар

* Python
* Tkinter
* Random
* Math

Қорытынды

Бұл жоба арқылы Python тілінде 2D ойын жасауды, кластармен жұмыс істеуді және объектілердің қозғалысын басқаруды үйрендім.
